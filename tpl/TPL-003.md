# 📚 TPL-003 — 근거 제시 규정

> **문서 지위: TPL-003 / 근거 제시 규정 / v1.0 / 기존 규정 이관본**
>
> 기준 문서: GOV-001 v2.2. GOV-001 부록 A의 기존 상세 기준을 사용자 요청에 따라 별도 문서로 이관한다.

공통 원칙: [GOV-001 — 협업 운영 규칙](../gov/GOV-001.md)

## 목적 및 적용 범위

이 문서는 사용자가 제시된 근거의 출처와 확인 위치를 추적하고, 근거의 종류·신뢰도·한계를 일관된 방식으로 판단할 수 있도록 근거 제시의 상세 기준과 표기 방식을 정한다. 협업 과정에서 근거를 제시할 때 적용하며, GOV-001의 공통 원칙과 승인·검증 요건을 대신하지 않는다.

## 근거 종류·신뢰도 등급 및 표기

### 1. 적용 원칙

① 이 부록의 등급은 협업에서 사용하는 자체 평가 기준이며, 자료 종류만으로 진실성을 보증하는 인증이 아니다. 등급은 **자료 전체가 아니라 해당 자료가 특정 주장을 뒷받침하는 정도**에 부여한다.

② 아래 기본 등급을 출발점으로 하되, 원문 확인 여부·직접성·발행 주체의 권한과 전문성·검증 방법·최신성·적용 범위·이해관계·다른 근거와의 상충을 검토하여 조정한다. 기본 등급과 다르게 부여한 경우 조정 이유를 짧게 기록한다.

③ 다른 AI의 출력과 사실에 관한 사용자 진술은 N을 표기하고 제5절에 따라 사용자에게 판단을 넘긴다. 그 밖에 원문을 확인하지 못한 자료에는 기본 등급을 그대로 부여하지 않고 E를 표기한다. 현재 AI의 해석·가정·사용자 결정은 GOV-001 제6조제1항에 따라 사실 근거와 구분하며, 그 자체에 A~E를 부여하여 외부 근거처럼 제시하지 않는다.

### 2. 근거 종류별 기본 등급

| 근거 종류 | 기본 등급 | 적용 범위와 조정 기준 |
|---|---|---|
| 공식 문서 | A | 법령·표준·공공기관 문서·공식 기술 문서 등. 발행기관의 권한·담당 범위 안에서 현행 원문이 해당 주장을 직접 뒷받침할 때 적용한다. 홍보성 주장이나 기관 밖의 일반적 효과까지 A로 보지 않는다. |
| 논문 | B | 동료심사를 거친 연구 논문. 연구 설계·자료·재현성·해당 주장과의 직접성을 검토하며, 충분히 검증된 직접 근거는 A로 조정할 수 있다. 미심사 사전 공개 논문은 원칙적으로 C 이하에서 검토한다. |
| 전문 보고서·서적 | B | 저자·발행기관·방법·근거가 확인되는 전문 자료. 이해관계, 검토 절차 및 원자료 확인 여부에 따라 조정한다. |
| 원자료·실험 기록 | B | 직접 관측·측정 데이터와 원본 기록. 수집 방법·무결성·검증 과정이 확인되어 해당 주장을 직접 지지하면 A로 조정할 수 있다. 기록의 존재와 결과의 타당성을 구분한다. |
| 인터넷 기사 | C | 언론사의 기사·취재 보도. 기자·발행일·취재원·원자료·독립 확인 여부를 검토한다. 공식 발표의 재전달은 가능한 경우 공식 원문을 우선 인용한다. |
| 위키 | D | 공동 편집형 참고 자료. 개요 파악과 원출처 탐색에 활용한다. 연결된 원출처를 직접 확인·인용한 경우에는 그 원출처의 종류와 등급을 표기한다. |
| 블로그·커뮤니티·SNS | D | 개인 게시물·경험담·토론 자료. 작성자·방법·원자료가 확인되면 해당 주장에 한하여 조정할 수 있으며, 익명·전언·출처 불명은 E로 처리한다. |
| 종류·출처 미확인 자료 | E | 출처 또는 원문을 확인하지 못한 자료. 사실 확정의 근거로 사용하지 않고 확인이 필요한 단서로 기록한다. |
| 다른 AI의 출력 | N | 다른 AI 세션·모델·에이전트가 생성한 답변·요약·분석 등. 원출처와 분리하여 기록하고, 해당 내용의 채택·배제·보류·추가 검증 여부는 사용자 판단에 맡긴다. AI 간 동의나 반복 인용으로 신뢰도를 높이지 않는다. |
| 사용자 진술 | N | 사용자가 제공한 관찰·경험·기억·실험값 등 사실에 관한 진술. 원자료·검증된 사실·사용자 결정과 구분하고, 해당 내용의 취급은 사용자 판단에 맡긴다. 작업 지시·승인·선택 등 명시적 의사표시는 이 분류가 아니라 사용자 결정으로 기록한다. |

### 3. 신뢰도 등급의 의미

| 등급 | 판정 기준 |
|---|---|
| A | 해당 주장을 직접 뒷받침하는 원문·원자료를 확인했고, 권한 또는 검증 방법·적용 범위·최신성이 적절한 강한 근거 |
| B | 저자·기관·방법·출처를 확인할 수 있는 신뢰할 만한 근거이나, 직접성·재현성·적용 범위 등에 제한이 남는 근거 |
| C | 출처를 추적할 수 있는 보도·2차 요약 또는 예비 연구로서, 원자료 확인이나 추가 검증이 필요한 근거 |
| D | 개요·탐색·경험 공유에 유용하지만, 검토 과정이나 원자료 확인이 부족하여 단독으로 사실을 확정하기 어려운 근거 |
| E | 출처·원문을 확인하지 못했거나, 해당 주장과의 연결이 불명확하거나, 중대한 신뢰성 문제가 있어 판단 근거로 채택하기 어려운 자료 |
| N | 사용자 판단 필요. 다른 AI의 출력 또는 사실에 관한 사용자 진술에 적용하는 별도 표지로서, A~E의 높낮이 서열에 포함하지 않는다. 사실 여부나 신뢰도를 AI가 확정하지 않고 해당 내용의 취급을 사용자에게 확인한다. |

### 4. 문장 끝 표기 규칙

① 외부 자료·원자료·다른 AI의 출력·사용자 진술을 근거로 사실에 관한 내용을 제시하는 문장은 출처 링크와 버전·절·쪽·표 등 확인 위치를 연결하고, 다른 AI의 출력·사용자 진술에는 가능한 세션·메시지·진술 일자 등 확인 위치를 기록하며, 문장 끝에 **\[종류 - 등급\]**을 병기한다. 표기는 출처 연결을 대신하지 않는다.

② 표기 예시는 **\[공식 문서 - A\]**, **\[논문 - B\]**, **\[인터넷 기사 - C\]**, **\[위키 - D\]**, **\[종류·출처 미확인 자료 - E\]**, **\[다른 AI의 출력 - N\]**, **\[사용자 진술 - N\]**과 같다. 예시는 형식을 보여 주며, 개별 자료의 실제 등급은 검토 결과에 따라 정한다.

③ 한 문장에 여러 출처를 제시하면 각 출처와 대응하는 종류·등급을 각각 병기한다. 서로 다른 주장이나 근거 수준이 섞이면 문장을 나누어 표기한다.

④ 자료의 한계·적용 조건·출처 간 상충·검증 필요는 등급 표기와 함께 명시한다. 최신 원문이나 후속 검증으로 판단이 달라지면 관련 문장과 등급을 갱신한다.

### 5. N 자료의 처리

① N 자료를 작업의 전제나 판단 근거로 채택할 필요가 있으면, AI는 내용·출처·미확인 사항과 영향을 제시하고 채택·배제·보류·추가 검증 여부를 사용자에게 확인한다. 사용자 판단 전에는 확인된 사실이나 승인된 실행 조건으로 취급하지 않는다.

② 사용자가 채택한 경우에는 승인 범위와 판단을 기록하되, 그 승인만으로 해당 진술의 사실성이 검증되거나 N이 A~E로 바뀐 것으로 보지 않는다.

③ 원출처·실험 기록 등을 별도로 확보하여 직접 검증한 경우에는 확인된 근거를 그 종류와 A~E 등급으로 따로 제시한다. 원래의 AI 출력·사용자 진술과 검증 결과의 관계를 기록한다. 여러 AI의 동의·재인용은 독립된 검증으로 인정하지 않는다.

## 제정 이력

- **v1.0 — 2026-10-09:** 사용자 요청에 따라 GOV-001 v2.2 부록 A의 적용 원칙, 근거 종류별 기본 등급, 신뢰도 등급의 의미, 문장 끝 표기 규칙 및 N 자료 처리 기준을 이관하여 제정. 기존 판단 기준은 유지하고 문서 간 참조만 정정함.
