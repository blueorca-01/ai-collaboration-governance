### 3.4 제5조제2항 — 목록·표·예시·부록의 사용 기준

- 변경 ID·승인: CHG-005. 확정자 도현, 2026-10-10.
- 수정 위치와 적용 전/후 상태:
  - 적용 전: `` ② **목록 및 표:** 지시의 실행 순서와 선후 관계가 중요할 때는 번호 목록을 사용하고, 병렬 조건·참고 정보·비교 정보에는 글머리표 또는 표를 사용할 수 있다. 제4조제3항의 `(1)`, `(2)` 등 세부 구분은 별도의 Markdown 제목 계층을 만들지 않는다. ``
  - 적용 후(제2항 전체를 다음으로 교체):

    ```markdown
    ② **목록·표·예시 및 부록:** 실행 지시 문서에서는 다음 각 호에 따라 사용한다.
    1. **번호 목록:** 실행 순서와 선후 관계가 있을 때 사용한다.
    2. **글머리표:** 순서 없는 병렬 조건이나 참고 정보를 나열할 때 사용한다.

    4. **예시:** 산출물이나 보고의 형식을 문장만으로 지시하기 어려울 때에만 사용한다. 예시임을 밝히고, 실제로 적용할 값·문안과 구분한다.
    5. **부록:** 도구별 실행 방식(제2조제6항제3호)이나 반복 참조할 긴 자료에만 둔다. 부록은 본문에서 참조한 범위에서만 적용하며, 부록에 본문에 없는 실행 명령을 두지 않는다.
    제4조제3항의 `(1)`, `(2)` 등 세부 구분은 별도의 Markdown 제목 계층을 만들지 않는다.
    ```

- 수정 행동과 선행 관계: 제2항을 교체한다. 마지막 문장(세부 구분)은 번호 목록 다음의 일반 문단으로 둔다. 선행 항목은 없다.
- 이유: 실행 AI가 예시를 명령으로 오인하지 않도록 예시·부록의 사용 기준을 추가한다.

       - `- **초안 v0.3 — [실행일 YYYY-MM-DD]:** 협업 작업 페이지 ‘작업공간_TPL002부록B처리’에서 확정된 변경(CHG-001~011)을 반영. 부록 B의 TPL-002-Q01~Q07을 모두 처리하고 처리 결과를 기록. 제1조제4항에 TPL-003 의존성을 명시하고 근거의 신뢰도 서술을 TPL-003으로 이관(제7조제4항제3호 개정, 제5호 삭제). 제3조제3항(문서 식별자)과 제3조제6항의 선택 항목 생략 문구를 삭제하고 항 번호는 유지. 제4조제2항에 절 구성 고정 문장을 추가하고, 제5조제2항을 목록·표·예시·부록의 5개 호로 교체. 제7조제1항제5호(부재 확인형 검증 기준) 신설, 제8조제5항(대체 전달 경로) 신설, 제9조제1항에 검증 기준 상충 점검 추가. 부록 A 첫 설명의 ‘최종 지시’를 ‘실행 지시 문서’로, 3.n의 근거 항목을 근거 표기 항목으로 수정. 이번 개정의 실행 지시 문서는 TPL-002 초안 v0.2 양식을 시험 적용하여 작성됨. 승인 기록: 도현, 2026-10-10.`
- 수정 행동과 선행 관계: 3.1~3.10을 수행한 뒤 마지막에 수행한다. 3.1~3.10 중 보류된 항목이 있으면, 이력 문장에서 그 항목에 해당하는 부분을 빼지 말고 그대로 적은 뒤 보고서에 보류 사실을 적는다. 사용자가 보고를 확인한 뒤 이력을 고친다.
- 보존 조건: 부록 D의 기존 두 항목은 바꾸지 않는다.
- 검증: 머리말의 버전이 `초안 v0.3`이고 날짜가 실행일과 같을 것. 부록 D가 세 항목이고 새 항목의 날짜가 머리말과 같을 것.
- 예외: 머리말 문안이 다르면 이 항목을 보류하고 보고한다.

### 3.12 공통 실행·검증·보고 조건

- 작성 기준과 근거 표기:
  - 이 문서는 TPL-002 초안 v0.2 양식을 시험 적용하였으며, 반드시 충족하는 기준은 PROC-001 제8조와 부록 C이다.
  - 이 문서는 TPL-002 초안 v0.2 제7조제4항제3호에 따라 TPL-003의 `[종류 - 등급]` 표기를 쓰지 않는다. TPL-003 제4절제1항과의 차이는 TPL-002-Q06으로 등록되어 이 문서의 3.1·3.6으로 해소되는 알려진 사항이며, 이 표기 방식은 사용자 승인에 따른 것이다. 이 차이를 충돌로 보고하거나 이 문서에 등급 표기를 추가하지 않는다.
  - 이 문서는 `[미확인]`·`[가정]` 표지를 사용하지 않는다.
- 공통 보존 및 금지 조건:
  - 제3절에 지정한 위치 외의 문안·서식·순서를 바꾸지 않는다. 띄어쓰기·맞춤법이 이상해 보여도 지시되지 않은 수정은 하지 않고 보고서의 ‘남은 문제’에 적는다.
  - 조·항·호의 번호와 부록 문자(A~D)는 바꾸지 않는다. 삭제는 `삭제` 표기로만 한다.
  - 굵게 표시된 항 제목(예: `**다른 규정과의 관계:**`), 페이지 멘션, 표의 구성은 지시된 경우 외에는 그대로 둔다.
  - GOV-001·PROC-001·TPL-001·TPL-003과 협업 작업 페이지는 수정하지 않는다.
  - 원본 페이지를 삭제하거나 복제본으로 바꾸지 않는다.
- 공통 검증·회귀 확인:
  - 각 작업 항목의 검증 기준을 확인한다.
  - 수정 전후를 비교하여, 제3절에 지정하지 않은 위치가 바뀌지 않았는지 확인한다.
  - 이 문서가 넣은 참조(제7조제4항제3호의 ‘제1조제4항’, 제8조제5항제3호의 ‘제2절’, 제5조제2항제5호의 ‘제2조제6항제3호’)가 실제 조문을 가리키는지 확인한다.
- 결과 보고 형식: 실행 대화에 다음 순서로 보고한다.
  1. 사전 점검 결과: 1~4단계 각각의 통과 여부와 확인한 내용
  2. 항목별 결과: 3.1~3.11 각각에 대해 `완료 / 부분 완료 / 미적용 / 실패` 중 하나, 판단 근거, 실제 수정 위치
  3. 공통 검증 결과: 회귀 확인과 참조 확인의 결과
  4. 남은 문제: 보류 항목과 그 이유, 지시와 원본의 차이, 수정하지 않았지만 발견한 문제
  5. 대체 경로를 사용한 경우: 그 사실과 반환 문서의 파일명
- 실행 AI 준수 원칙(상세 원칙은 GOV-001 제9조 참조):
  1. 작업이 불가능하거나 필요한 검증을 수행할 수 없으면 제한을 임의로 우회하거나 검증되지 않은 대체 결과를 완료·검증 성공으로 보고하지 않는다. 해당 작업을 중단하고 이유·영향 범위·필요 조건을 보고한다.
  2. 결과를 통과시키기 위하여 검증 기준·임계값·검증 대상·절차를 임의로 변경·완화·생략하거나 검증 데이터·결과·판정을 조작하지 않는다. 검증 기준이 다른 지시와 충돌하면 기준을 바꾸지 말고 충돌을 보고한다.
- 근거 표기: 이 문서는 근거 표기를 사용하지 않는다.

## 5. 실행 제외 항목(선택)

- 이 절은 참고 정보이며 실행 AI는 이 항목을 수행하지 않는다.
- TPL-003 후속 개정: 이관된 신뢰도 서술(가정 표지 등)의 정비. 이 작업 이후 별도 작업으로 진행한다.
- TPL-001 부록 B 안내문의 ‘제안 단계’ 표현: TPL-001 수정은 범위 밖이다. 사용자가 지정할 때 재검토한다.
- 대체 전달 경로의 반영·검증 절차: 실행·검증 절차이므로 PROC-002 제정 시 다룬다.
- 설계 AI의 자기검증 한계: 검토 주체 문제로 PROC-002 제정 시 다룬다.
